⚡ Golden Rules (non-negotiable)

  • Every cut has a full, copy-paste prompt. 🆕 WIDE = the main shot. 🔍 CLOSE-UP = the punch-in beat — you can EITHER generate it as its own image (it’s a tighter framing of the shot just before it) OR simply zoom the previous image in CapCut to save a generation. Either way you get a new visual every ~3–4 seconds, like Zenn.
  • NO text inside any generated image. All words added in CapCut (see each Editing note).
  • True stick figures only — white circle head (~¼ body), uneven circle eyes with pupil dots, line mouth, no nose, single-line lanky limbs, loop hands, no body fill, no clothing.
  • Characters differ ONLY by hair, face, glasses, hat, tie. Same body every time.
  • Attach the reference images (📎) — character anchor + previous shot — to lock consistency & continuity.
  • Flat warm cream background, single muted ground strip, dusty muted colors. No gradients, no shading.
  • Fast cuts. Aim for a visual change every ~3 seconds. The REUSE cuts are what hit that rhythm.
